# Pastelería Nelly

Sitio web de Pastelería Nelly, en Linares, Nuevo León. Galería de pasteles personalizados, postres y diseños para celebraciones.

- [Visitar el sitio](https://abiudsm.github.io/PasteleriaNelly/)
- [Instagram](https://www.instagram.com/pastelerianelly_linares/)
- [Facebook](https://www.facebook.com/profile.php?id=100052178664824)

## Estructura

- `index.html`: inicio y selección de creaciones.
- `posts.html`: galería con filtros.
- `about.html`: presentación de la pastelería.
- `404.html`: página de error.
- `assets/`: estilos, JavaScript e imágenes locales optimizadas.
- `content.json`: contenido del sitio y enlaces a las publicaciones originales.
- `sitemap.xml` y `robots.txt`: información para buscadores.

## Vista previa local

Desde la carpeta del proyecto:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Abre `http://127.0.0.1:8000/` en el navegador. No requiere instalar dependencias ni compilar.

## Publicación

GitHub Pages publica la rama `main`, carpeta `/ (root)`. Los cambios subidos a esa rama se despliegan automáticamente.

Las fotografías y los enlaces de la galería corresponden a publicaciones de la cuenta de Instagram. Para pedidos y disponibilidad, consulta por mensaje directo.
